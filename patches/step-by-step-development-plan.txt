Step 2 - Server AI provider routes
Files:

Goal:
- Add /api/ai/generate-image.
- Add /api/ai/generate-video.
- Add /api/ai/:type-status/:provider/:taskId.
- Keep old /api/generate-image and /api/generate-video for compatibility.
- Add DashScope and Volcengine provider adapters behind a unified response shape.

Validation:
- npm run dev
- curl -s http://localhost:3000/api/health
- curl -s -X POST http://localhost:3000/api/ai/generate-image -H 'Content-Type: application/json' -d '{"provider":"dashscope"}'
- curl -s -X POST http://localhost:3000/api/ai/generate-video -H 'Content-Type: application/json' -d '{"provider":"volcengine","prompt":"test"}'
- The last two commands should return controlled 400 validation errors without crashing the server.
