# PWA / 小程序 / 桌面宠物业务边界分析

更新时间：2026-05-18

## 当前定位

`Miao_remote` 仍是 PWA/Web + Express 服务主工程，本轮新增的桌面宠物能力属于 Web 工程的桌面端扩展，不替代 Taro 小程序或原生微信小程序工程。

## 功能复用关系

- 猫咪资料、动作视频、生成结果：复用现有 Web 服务和本地缓存。
- 桌面悬浮、置顶、托盘、点击穿透：由 Electron 独立提供，小程序端不具备同类能力。
- 视频抽帧：服务端从已持久化的本地视频生成 PNG 序列，供桌面宠物减少视频播放卡顿或背景违和。

## 业务风险

- 桌面端没有天然微信/浏览器登录态，需要明确用户身份绑定方式。
- 桌宠 API 不能裸露到公网；远程部署必须配置 `MIAO_DESKTOP_TOKEN` 或接入正式账号 token。
- 抽帧会产生大量文件，必须保留清理策略和并发限制。

## 验收重点

- Web/PWA 创建猫咪后，桌面宠物可以读取当前用户猫咪。
- 切换猫咪后，托盘菜单、浮窗展示和本地 active cat 状态一致。
- 生成帧动画后，`uploads/frames` 不持续堆积过期目录。
- 远程 `MIAO_APP_URL` 未配置 token 时，桌宠 API 应拒绝访问。
